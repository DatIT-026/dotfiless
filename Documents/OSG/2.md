**Nix fundamental**

1. Nix is not a programming languages, it is for BDSM user.
  
- Purely Functional Languages (PFL)
- Expression vs Statement:
  - Expression return a value.
  - Statement has lots of Expressions.
  
  e.g: This is a statement:
      ```C
      int main() {
        int a = 1+5;
        return a;
      }
      ```
    In the statement, `1+5`, `a` is an expression.

  PFL does not have Statement. Only expression. For example:
   
  ```Nix
  if (a < 3) "Less than 3" else "Not less than 3"; //`else` is not optional
  ```
