1. DNS (Domain Name Services) Server: 3 layers
  - Highest layer: saves the domain: google.com, microsoft.com
  - Middle layer: .com; .org; .tk; ... -> map
  - Lowest layer: root name server

  DNS, HTTPS --> UDP (DNS use this), TCP/TLS --> IP (lowest)

  Example: PC ---(google.com)-> 1.1.1.1 ---(.com)--> root name server ---(IP .com)---
      --> .com --> 1.1.1.1 --> ip of google.com --> PC

  New tech: DNS over TLS (DoT) & DNS over HTTPs (HoH)
